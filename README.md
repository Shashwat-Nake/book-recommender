# 📚 Book Recommendation System

A Machine Learning based Book Recommendation System developed using Collaborative Filtering and Cosine Similarity. This project recommends similar books to users based on book rating patterns and user preferences.

## 🚀 Features

* Book search functionality
* Personalized book recommendations
* Collaborative filtering algorithm
* Cosine similarity based recommendation engine
* Data visualization for popular books
* Interactive Streamlit web application
* Global deployment support

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Streamlit

## 📊 Machine Learning Technique

This project uses Collaborative Filtering with Cosine Similarity to find similar books and generate recommendations based on user rating behavior.

## 📂 Dataset

Dataset used from Kaggle Book Recommendation Dataset.

## 🌐 Live Project

Deployed using Streamlit Community Cloud for global access.

## 🎯 Project Objective

To build an intelligent recommendation system that helps users discover books similar to their interests using Machine Learning techniques.
